Como usar a tag para links

A tag usada para criar links em HTML é a tag < a > (chamada de tag âncora), combinada com o atributo href para indicar o endereço de destino.
Abaixo um exemplo de como usar

< a href="http://" target="_blank" rel="noopener noreferrer"> >
